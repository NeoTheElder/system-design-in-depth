# System Design In Depth

Interactive system-design explainers and practice papers, built as Claude artifacts.

Browse: https://neotheelder.github.io/system-design-in-depth/

## Add an artifact

1. Save the artifact's HTML as `artifacts/<slug>.html`.
2. Add a `<li>` for it in `index.html`.
3. Commit and push. GitHub Pages redeploys in about a minute.
